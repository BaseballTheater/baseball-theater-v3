# A7 — Standings tables fit their content; mobile names shorten (S4)

Amends the ratified [standings-search-settings design](../DESIGN.md) (ratified 2026-10-14) and its [A1](A1.md)–[A6](A6.md). Story **S4**. A written amendment: the owner's directions at S4's design match, ratified as words (no Figma frames). The S4 captures that match it become its drawn record.

**Adds:** horizontal scroll for a division table wider than the screen.
**Overrides:** `standings-mobile`, `standings-medium`, `standings-desktop`: each division table is as wide as its content needs, not the full width of the page. On mobile each team is its abbreviation (`NYY`, `DET`) beside its swatch instead of its full name.
**Repeals:** the full-width tables, and on mobile the full team names.

## Frames

None. The original frames stand for everything this amendment doesn't change; the captures at S4's design match show the change.

## Decisions

Recorded as the owner stated them, on 2026-11-02, at S4's design match: "The table should not be 100% width; it should only be as wide as it needs to be, and should scroll if it's wider than the viewport. On mobile, the names should shorten to just the abbreviated name (NYY, DET, etc)".

## Interpretation

- *Agent:* on mobile the abbreviation takes the team column, so the separate abbreviation column is dropped there (it would repeat the same three letters). Medium and desktop keep full names and the abbreviation column.
- *Agent:* the table scrolls inside its own box, so the page never scrolls sideways.
