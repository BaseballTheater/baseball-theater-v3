**Gap:** BT knows each pitch's speed, spin and break but not what is normal for the pitcher, so it can't say "1.5 mph above his average". Savant's `pitcher-yearly-averages` feed gives each pitcher's season averages per pitch type, for any list of pitchers in one call (owner, 2026-10-30, asked whether the two game-context Savant feeds should join "More MLB game data" as stories: *"1. Yes"*). What it holds: `docs/v3/SAVANT-DATA.md`.

**Impact:** Before S104, BT could show how a pitch moved but not whether that was usual for the pitcher. S104 impact: BT keeps every pitcher's season norms per pitch type for the games it follows, ready for the Live and Plays rooms to compare each pitch with.

**Acceptance criteria** (checks `scripts/verify-S104.sh` performs)

1. `fixtures/raw/savant-pitcher-averages-823823.json` holds Savant's response to `https://baseballsavant.mlb.com/gamefeed/pitcher-yearly-averages?pitchers=[{ids}]` for the pitchers who pitched in 823823 (from the live feed), recorded once with `BT_USE_LIVE_MLB=1` and committed; tests and local dev read it, never the network.
2. `packages/mlb-api` types a pitcher row as named interfaces and parses it with zod. The fields are per pitch type, with a prefix (`ff_avg_speed`, `sl_avg_spin`, …), so the parser reads every pitch-type prefix the recording has, not a hand-written list per pitch. A parse test runs on the recording, and `pnpm mlb:scan-drift` covers it.
3. `MlbStatsClient` gains `fetchPitcherSeasonAverages(pitcherIds)`, in the fixture and HTTP adapters. Ingest owns the call (ADR-002), and no web code fetches it.
4. A mapper projects it into BT's own shape, `GameSnapshot.pitcherAverages`, keyed by pitcher id and then by MLB's pitch-type code. Each entry holds usage (count and share), the average and range of speed, spin, horizontal break, vertical and induced vertical break, spin axis, and release point x / y / z, plus the season it covers. A pitcher Savant returns no row for is absent, never zero (tests on the recording). Additive to the payload (`pnpm api:breaking` exits 0).
5. **Cadence:** fetched once for the starting pitchers when the game enters its live window, and once for each reliever the first time he appears; never once per pitch (test with a counting fake over the 823823 replay: as many calls as distinct pitchers entering, at most).
6. The source is optional: when Savant fails or returns nothing, `pitcherAverages` is absent and the game is served as before (test).
7. This file's S104 **Status** (story heading and top table) is `done`.
