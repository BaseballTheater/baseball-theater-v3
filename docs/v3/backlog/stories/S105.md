**Gap:** A spray chart needs the park's shape. Savant serves a field outline for each park at `https://baseballsavant.mlb.com/site-core/images/fields/{venueId}.svg`, keyed by MLB's venue id: 3313 is Yankee Stadium, and 4169 returns loanDepot park, 823823's venue (`gameData.venue.id`) (owner, 2026-10-30, asked whether the two game-context Savant feeds should join "More MLB game data" as stories: *"1. Yes"*). BT keeps the venue id (`GameSnapshot.venue.id`) but no drawing. Details: `docs/v3/SAVANT-DATA.md`.

**Impact:** Before S105, BT had no picture of the ballpark to plot batted balls on. S105 impact: BT serves each park's field outline itself, ready for a spray chart of where the balls went (S103's spray positions).
