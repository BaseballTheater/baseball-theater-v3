**Gap:** BT knows each play's result but not what it meant: no win probability, no record of which plays MLB counts as key moments or lead changes, and no list of ABS challenges. MLB's `bdfed` play-metrics feed has all of it per at-bat (owner, 2026-10-30: *"Also add stories to ingest all of this extra data."*).

**Impact:** Before S93, BT could only guess which plays mattered from the words in a clip's title. S93 impact: BT keeps MLB's own measure of every play — how much it swung the odds of winning, and whether it was a key moment, a lead change, a hard hit or an ABS challenge — ready for the videos, plays and rankings to use.

**Acceptance criteria** (checks `scripts/verify-S93.sh` performs)

1. `fixtures/raw/playmetrics-823823.json` holds MLB's response to `https://bdfed.stitch.mlbinfra.com/bdfed/playMetrics/{gamePk}?keyMoments=true&scoringPlays=true&homeRuns=true&strikeouts=true&hardHits=true&highLeverage=false&leadChange=true&winProb=true&absChallenge=true` for 823823, recorded once with `BT_USE_LIVE_MLB=1` and committed; tests and local dev read it, never the network.
2. `packages/mlb-api` types the payload as named interfaces split by purpose and parses it with zod; a parse test runs on the recording, and `pnpm mlb:scan-drift` diffs it against the parser like the other payloads.
3. `MlbStatsClient` gains `fetchPlayMetrics(gamePk)`, implemented by the fixture adapter and the HTTP adapter; ingest owns the call (ADR-002): no web code fetches it.
4. A mapper in `functions/src/mappers/` projects it into BT's own shape, `GameSnapshot.playMetrics`, added to the game payload additively (regeneration test; `pnpm api:breaking` exits 0). Per at-bat (`atBatIndex`): home / away win probability and win probability added, and the flags key moment, lead change, scoring, home run, hard hit, strikeout, high leverage, ABS challenge, plus hit data (launch speed, angle, distance); on 823823 the ABS-challenge at-bats are 34, 39, 69, 82 and 83 and the key moments are 14 (test).
5. The source is optional: when the call fails or returns nothing, the field is absent and the game is served as before (test).
