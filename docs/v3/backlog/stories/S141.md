**Gap:** The owner wants a footer like most sites have, with a few columns of links (owner, 2026-11-10: *"we need probably a footer like banner kind of section-y thing like most places have where there's a few columns of links and stuff"*), holding a copyright line, the policies, a link to the fan's data, an about page and a way to make contact, and wants the "Fetched … ago" line gone (*"I don't think we need the fetched thing at all"*; *"But I think the footer needs to change quite a bit."*). The ratified footers are one muted line, "Fetched {age} · baseball.theater" (game-shell A3, game-rooms A4), and nothing draws a footer of links, so S142 can't build it without designing in code (rule 18). On 2026-11-10 (evening) the owner made the footer just links, from a ratified list of links and destinations, with no pages of text (AC 1–2); none of the pages first named (policies, about, contact) exists.

**Impact:** Before S141, nothing showed what the site's footer looks like or which links it holds. S141 impact: the owner approves the footer and its list of links, and where each goes, before S142 builds it.
