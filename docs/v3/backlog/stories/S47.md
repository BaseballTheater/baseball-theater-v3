**Gap:** ADR-021 applies the cache-lifetime ladder twice — the edge `s-maxage` and the MLB refresh-on-read — with `stale-while-revalidate`. At HEAD handlers send no `Cache-Control` and `functions/src/services/refresh.ts` uses a fixed `CACHE_TTL_MS`. `scripts/verify-S17.sh` check 1 greps `export const CACHE_TTL_MS`, so it stays as the documented floor. Inserted by the 2026-10-18 backlog review (two independent fresh-context reviewers, merged).

**Impact:** Before S47, every finished game was re-fetched from MLB every few minutes for as long as anyone looked at it. S47 impact: the longer a game goes unchanged, the longer Cloudflare serves it straight from its cache, so finished games stop costing MLB calls and database reads within hours — while a correction still shows up within two days at most.

**Parked for the owner (2026-10-30 backlog review, after S45):** on Cloudflare a Worker runs *in front of* the cache, so a `Cache-Control: s-maxage` header on a response the Worker builds is not stored at the edge by itself (Cloudflare docs, "How the cache works": *"Cloudflare Workers run before the cache"*). Two ways to get ADR-021's edge cache, and they differ in cost and behavior:

- **Workers Cache:** `"cache": { "enabled": true }` in `wrangler.jsonc` (wrangler 4.149.0's schema has it). Cloudflare then checks the cache before running the Worker, honors `Cache-Control` per RFC 9111 (`stale-while-revalidate` included), and is *"tiered by default"*, as ADR-021 asks. But *"when caching is enabled, every request to your Worker is charged at the standard Workers request rate … including requests that are normally free: static asset requests"*, which changes ADR-017's cost line.
- **Cache API** (`caches.default.match` / `put` in the Worker): no billing change, but *"The Cache API is not compatible with tiered caching"* (one data center at a time), and the Worker still runs on every request.

**Answered (owner, 2026-10-30): "Workers cache".** The edge cache is Workers Cache, so ADR-021's tiered edge cache holds as written and ADR-017's cost line now includes every request at the Workers rate (static assets too); recording that in ADR-017 is left to the next backlog review, outside this fence. New AC 6 enables it in `wrangler.jsonc`; AC 5's README line names it. Back to `todo`.
